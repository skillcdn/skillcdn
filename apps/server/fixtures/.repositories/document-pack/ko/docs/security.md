# 보안 수칙

보안은 모두의 일이다. 이 문서는 누구나 지켜야 할 최소한의 규칙을 정한다.

## 비밀번호와 이중 인증

회사 계정의 비밀번호는 열두 자 이상이어야 하고, 다른 서비스에서 쓰는 비밀번호와 같으면 안 된다. 비밀번호 관리 프로그램을 회사가 제공하며, 모든 계정에 이중 인증을 켠다. 비밀번호를 메신저나 이메일로 보내지 않고, 공유가 필요하면 비밀번호 관리 프로그램의 공유 기능을 쓴다.

## 사무실 출입

출입 카드는 본인만 쓴다. 카드를 두고 왔으면 안내 데스크에서 임시 카드를 받고, 다른 사람의 카드로 들어가지 않는다. 방문자는 안내 데스크에서 등록하고 방문자 카드를 받으며, 초대한 직원이 사무실 안에서 동행한다. 마지막으로 퇴근하는 사람은 창문과 회의실 문을 닫고 소등한다.

## 문서 보안 등급

문서는 공개, 내부, 기밀 세 등급으로 나눈다. 공개 문서는 누구에게나 보여도 되고, 내부 문서는 직원에게만 보이며, 기밀 문서는 지정된 사람에게만 보인다. 기밀 문서는 회사 저장소 밖으로 내보내지 않으며 인쇄하지 않는다. 등급은 문서를 만든 사람이 정하고 첫 줄에 적는다.

## 사고 신고

계정이 해킹된 것 같거나, 장비를 잃어버렸거나, 의심스러운 이메일의 링크를 눌렀으면 즉시 보안팀 비상 번호로 알린다. 실수를 숨기는 것이 가장 큰 사고다. 신고한 사람은 책임을 묻지 않으며, 보안팀은 접수 후 한 시간 안에 조치 상황을 알린다.
