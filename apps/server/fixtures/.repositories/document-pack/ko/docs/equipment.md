# 장비 규정

회사가 지급한 장비는 회사의 자산이며, 쓰는 사람이 관리한다.

## 지급 기준

입사 때 노트북 한 대와 모니터 한 대가 기본으로 지급된다. 노트북은 삼 년마다 새 것으로 바꿀 수 있고, 모니터는 고장 날 때까지 쓴다. 개발이나 디자인처럼 더 좋은 사양이 필요한 직무는 매니저의 승인으로 상위 모델을 받는다. 키보드와 마우스, 헤드셋은 장비팀에 요청하면 재고 안에서 바로 받는다.

## 고장 신고

장비가 고장 나면 장비 시스템에 증상을 적어 신고한다. 장비팀이 하루 안에 확인하고, 수리에 사흘 이상 걸리면 그동안 쓸 대체 장비를 빌려준다. 스스로 분해하거나 외부 수리점에 맡기지 않는다.

## 분실과 파손

장비를 잃어버리면 즉시 장비팀과 보안팀에 알린다. 보안팀은 원격으로 장비의 데이터를 지우고 계정을 잠근다. 업무 중의 사고로 파손된 장비는 회사가 비용을 부담하고, 고의나 중대한 부주의로 파손되거나 분실된 장비는 감가상각을 적용한 금액의 절반을 본인이 부담한다.

## 퇴사 시 반납

마지막 근무일에 노트북, 모니터, 출입 카드와 그 밖에 지급받은 모든 장비를 장비팀에 반납한다. 반납 전에 개인 파일은 스스로 지우되, 업무 파일은 지우지 않고 매니저에게 인계한다. 반납이 확인되어야 마지막 급여가 지급된다.
