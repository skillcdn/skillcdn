# Tidewell handbook

A test-only document pack: the product handbook of Tidewell, a fictional scheduling and invoicing app for small field-service companies made by the fictional Saltmarsh Software, and, under `ko/`, the internal handbook of a fictional Korean office. Everything here is invented for the retrieval evaluation set in `apps/server/fixtures/retrieval/`; nothing in it describes a real product, company or person.

- `docs/`: the English handbook, one file per topic, each with a map in `docs/README.md`.
- `ko/docs/`: the Korean handbook, with its own manifest declaring the language.
