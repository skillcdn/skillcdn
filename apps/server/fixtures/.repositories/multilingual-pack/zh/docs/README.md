# 青岚材料研究院与青岚联合保障旅的文件库

本文件库收录青岚材料研究院的实验室管理规程与文德雷尔联邦军青岚联合保障旅的手册、规定与教材，全部以中文撰写，是文德雷尔联邦研究与国防物资办公室多语言文件库的中文部分。各文件各述其事，不是其他语言文件的译本。
