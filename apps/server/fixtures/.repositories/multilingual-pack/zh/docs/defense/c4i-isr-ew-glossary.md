# C4I、ISR 与电子战术语手册

本手册供青岚联合保障旅的参谋人员、通信分队与文书人员使用，统一本旅文件中与指挥控制、情报侦察和电子战有关的术语写法。本手册的定义取自公开的联邦军术语标准 VDS 4301，不涉及任何具体系统的性能参数。

## C4I 的定义及五个要素

C4I 是指挥（Command）、控制（Control）、通信（Communications）、计算机（Computers）与情报（Intelligence）的合称，指指挥员借以了解态势、作出决定并把命令传达给部队的人员、程序与装备的总体。指挥指指挥员依法对部队行使的权力；控制指为落实指挥员意图而对部队活动进行的调整；通信指信息在各级之间的传递；计算机指处理、存储与显示信息的设备；情报指经过搜集、处理与分析而形成的、关于环境与对方的知识。本旅文件中将 C4I 视为一个整体能力，而不是五个独立的科目。

## ISR 的含义与三者的关系

ISR 是情报（Intelligence）、监视（Surveillance）与侦察（Reconnaissance）的合称。侦察是为获取特定信息而在特定时间对特定地区或目标进行的一次性活动；监视是对地区、目标或人员持续的、系统的观察；情报是对侦察与监视所得信息以及其他来源的信息进行处理与分析后形成的产品。三者的关系是：侦察与监视是搜集手段，情报是分析的结果，而情报需求又反过来确定侦察与监视的任务。本旅文件中“ISR 资源”指承担搜集任务的人员与装备，“ISR 产品”指分析后下发的情报报告。

## 电子战的三个组成

电子战（EW，Electronic Warfare）是利用电磁能量控制电磁频谱或攻击对方的军事行动，分为三个组成部分。电子攻击（EA，Electronic Attack）指使用电磁能量、定向能或反辐射武器攻击人员、设施或装备，包括干扰与欺骗；电子防护（EP，Electronic Protection）指保护己方人员、设施与装备免受敌方或己方电子战影响的措施，如频率管理与发射控制；电子支援（ES，Electronic Support）指为识别威胁而搜索、截获与定位电磁辐射源的行动。三者在本旅文件中应分别写明，不得以“电子对抗”一词笼统代替。

## 态势感知与通用作战图

态势感知（SA，Situational Awareness）指对所处环境中的要素、其含义以及近期变化的认知，是指挥员作出决定的基础。通用作战图（COP，Common Operational Picture）是由多个指挥所共享的、经统一标准处理的相关信息的单一显示，使各级指挥员对同一态势有一致的认识。COP 的内容一般包括己方部队位置、已知对方位置、地形与气象、后勤状态与任务进度。本旅的 COP 由旅指挥所信息中心在「ZT-7 态势终端」上维护，各营指挥所每 30 分钟上报一次位置与状态。COP 显示的符号应符合联邦军统一的军队标号规定。

## 数据链的一般概念

数据链（data link）是在平台、传感器与指挥所之间按约定的报文格式自动交换数字信息的通信手段，与话音通信相比具有速度快、格式统一、便于计算机处理的特点。数据链由网络参与者（participant）、报文标准、传输介质与网络管理构成。战术数据链（TDL，Tactical Data Link）用于交换航迹、识别、指挥命令与状态信息。本手册只规定术语，本旅使用的数据链型号、频率、报文内容与网络参数见保密的通信电子作战规定，不在本手册中引用。本旅文件中“航迹”指对一个目标的连续位置报告，“本机报告”指平台对自身位置与状态的报告。

## 术语对照表

本旅文件使用下表的中文译名与英文缩写，缩写的大小写与此表一致。

| 中文 | 英文缩写 |
|---|---|
| 指挥、控制、通信、计算机与情报 | C4I |
| 情报、监视与侦察 | ISR |
| 电子战 | EW |
| 电子攻击、电子防护、电子支援 | EA、EP、ES |
| 态势感知 | SA |
| 通用作战图 | COP |
| 战术数据链 | TDL |
| 电磁频谱 | EMS |

表中未列的术语应按 VDS 4301 的译名；VDS 4301 也未列的，由旅参谋部术语管理员确定并补入本表。本表每年随手册再版一次，中间的补充以旅参谋部通知形式下发，通知编号写入下一版的修订记录。

## 在本旅文件中的用法

术语在一份文件中首次出现时应写中文全称并在括号内注明英文缩写，例如“电子防护（EP）”，其后可只用缩写。缩写不加中文后缀重复含义，不得写“EW 战”或“COP 图”。中英文混排时缩写前后各留一个半角空格。命令与报告中涉及电子战的内容应区分三个组成部分，不得只写“实施电子战”。文件的标题中不使用缩写，正文表格中可以使用。引用 ISR 产品时应注明情报等级与时效，但本手册不规定情报等级的划分，划分见旅情报规定。手册中未收录的外文缩写在文件中出现时应附中文解释。

## 术语的变更管理

术语的新增、修改与废止由旅参谋部术语管理员受理，申请人填写「表格 青保-61 术语变更申请表」，写明现有写法、拟定写法、理由与涉及的文件。术语管理员在 10 个工作日内给出意见，并提交旅术语委员会每季度一次的例会决定。通过的变更以旅参谋部通知下发，自下发之日起 30 天后新文件应使用新术语，已发布的文件在下一次修订时统一替换。废止的术语在手册中保留一个版本周期并标注“已废止”，以便读者对照旧文件。术语管理员保存全部变更申请表 5 年。
