# 青岚材料研究院的实验室管理规程

本目录收录青岚材料研究院的四份实验室管理规程，供本院人员、外来人员与承包方查阅。

| 文件 | 内容 |
|---|---|
| [洁净室管理规程](cleanroom.md) | 洁净度分区与 ISO 等级命名、更衣与风淋、压差与换气、粒子监测频次、传递窗与物料进入、耗材与清洁剂、停机后的再验证 |
| [危险化学品管理规程](hazardous-chemicals.md) | 分类储存与隔离、剧毒品双人双锁、台账编号 QL-HC、SDS 的获取与存放、废液交接、泄漏应急、通风柜使用、年度盘点 |
| [高压气瓶与低温介质管理规程](gas-cylinders-and-cryogenics.md) | 气瓶颜色标识与检验周期、固定与存放间距、减压阀与检漏、液氮与杜瓦瓶、低温防护装具、氧含量报警阈值、冻伤处置、气瓶退库 |
| [设备维护管理规程](equipment-maintenance.md) | 三级维护、备件与易损件清单、报修单编号 QL-WO、停机记录与设备档案、返厂、验收与报废、维护人员资格、年度维护计划 |
