# 서돌재료연구원과 서돌 군수지원단의 문서 모음

벤드렐 연방 연구개발물자청(ORDM) 자료실의 한국어 문서로, 서돌재료연구원의 연구 규정과 벤드렐 연방군 서돌 군수지원단의 군수 규정을 담는다. 각 문서는 자기 주제의 사실만을 다루며 다른 언어 문서의 번역이 아니다.
