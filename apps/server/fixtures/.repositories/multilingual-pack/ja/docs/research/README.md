# 蒼陵計測研究所の研究文書

蒼陵計測研究所の計測管理と品質システムに関する規程及び要領を収める。

| 文書 | 内容 |
|---|---|
| [計測器の校正及び点検に関する規程](calibration-and-inspection.md) | 計測器ごとの校正周期、トレーサビリティ、校正証明書の番号、不確かさの表し方、校正ラベル、期限超過時の処置、点検の区別、記録の保存年限 |
| [試験装置の運用要領](test-equipment-operation.md) | 恒温恒湿槽、振動試験機、万能試験機、落下試験機の予約、使用資格、運転前後の点検と記録、異常時の措置、治具、安全、消耗部品、定期保守 |
| [標準物質及び参照標準の管理規程](reference-materials.md) | 認証標準物質の受入れと登録番号、保管条件、開封後の有効期限、使用記録と残量、分銅の等級、標準温度計と標準抵抗器、廃棄、相互比較 |
| [試験報告書の作成及び管理規程](test-reports.md) | 報告書番号、様式と必須記載事項、不確かさの記載、承認フロー、電子署名、改訂、発行と再発行、保管年限と検索、記載禁止事項 |
