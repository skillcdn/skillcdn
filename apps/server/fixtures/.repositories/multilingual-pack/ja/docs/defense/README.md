# 北嶺地区支援隊の部隊文書

ヴェンドレル連邦軍北嶺地区支援隊の車両、野外衛生、地図判読及び通信機器に関する要領と教範を収める。

| 文書 | 内容 |
|---|---|
| [車両の運行前後点検及び燃料・油脂類の取扱要領](vehicle-inspection-and-fuel.md) | 運行前後の点検項目、燃料・油脂類の連邦呼称、給油時の静電気対策と消火器、運行記録と燃費、故障の報告、冬季の追加点検、タイヤ、整備要求 |
| [野外衛生及び飲料水の確保に関する要領](field-sanitation-and-water.md) | 飲料水の確保と浄水、残留塩素、給水車と給水袋の清掃、糧食の保管、野外トイレと廃棄物、手洗いと食器の消毒、熱中症、衛生検査の記録 |
| [地図判読教範](map-reading.md) | 縮尺と図式、UTM 図法と MGRS 座標、三つの北と偏角、等高線、距離の測定、コンパス、交会法、地図の保管と更新 |
| [携帯無線機の手入れ及び管理要領](communications-equipment-care.md) | 日常手入れ、アンテナ、バッテリー、接地、電磁干渉、妨害の兆候と報告、防水と結露、故障の切り分けと返納 |
