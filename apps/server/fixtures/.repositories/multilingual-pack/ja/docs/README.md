# 蒼陵計測研究所と北嶺地区支援隊の文書集

研究・防衛資材庁（ORDM）の文書館に収められた日本語の文書で、蒼陵計測研究所の研究文書とヴェンドレル連邦軍北嶺地区支援隊の部隊文書からなる。いずれの文書も他の言語の文書の翻訳ではなく、それぞれ固有の主題と事実を記す。

## 研究文書（蒼陵計測研究所）

| 文書 | 内容 |
|---|---|
| [計測器の校正及び点検に関する規程](research/calibration-and-inspection.md) | 計測器ごとの校正周期、トレーサビリティ、校正証明書の番号、不確かさの表し方、校正ラベル、期限超過時の処置、点検の区別、記録の保存年限 |
| [試験装置の運用要領](research/test-equipment-operation.md) | 恒温恒湿槽、振動試験機、万能試験機、落下試験機の予約、使用資格、運転前後の点検と記録、異常時の措置、治具、安全、消耗部品、定期保守 |
| [標準物質及び参照標準の管理規程](research/reference-materials.md) | 認証標準物質の受入れと登録番号、保管条件、開封後の有効期限、使用記録と残量、分銅の等級、標準温度計と標準抵抗器、廃棄、相互比較 |
| [試験報告書の作成及び管理規程](research/test-reports.md) | 報告書番号、様式と必須記載事項、不確かさの記載、承認フロー、電子署名、改訂、発行と再発行、保管年限と検索、記載禁止事項 |

## 部隊文書（北嶺地区支援隊）

| 文書 | 内容 |
|---|---|
| [車両の運行前後点検及び燃料・油脂類の取扱要領](defense/vehicle-inspection-and-fuel.md) | 運行前後の点検項目、燃料・油脂類の連邦呼称、給油時の静電気対策と消火器、運行記録と燃費、故障の報告、冬季の追加点検、タイヤ、整備要求 |
| [野外衛生及び飲料水の確保に関する要領](defense/field-sanitation-and-water.md) | 飲料水の確保と浄水、残留塩素、給水車と給水袋の清掃、糧食の保管、野外トイレと廃棄物、手洗いと食器の消毒、熱中症、衛生検査の記録 |
| [地図判読教範](defense/map-reading.md) | 縮尺と図式、UTM 図法と MGRS 座標、三つの北と偏角、等高線、距離の測定、コンパス、交会法、地図の保管と更新 |
| [携帯無線機の手入れ及び管理要領](defense/communications-equipment-care.md) | 日常手入れ、アンテナ、バッテリー、接地、電磁干渉、妨害の兆候と報告、防水と結露、故障の切り分けと返納 |
