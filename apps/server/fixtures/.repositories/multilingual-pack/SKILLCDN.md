# Rules for reading this library

Every folder is one language, declared by its own manifest, and no document is a translation of another. Read the map `README.md` of a folder before searching in it, search in the language the documents are written in or in your own, and read the section a result names before answering. Quote a code, a number or a period rather than paraphrasing it.
