# Annex C Code tables

Annex C of the Tidewater Link Protocol, third edition: the codes a station reports its condition with, and the modifiers that say what the condition applies to. TABLE C-2 is long and stands in 3 files, 20 rows to a section.

- [TABLE C-1 Station condition codes](010-table-c-1-station-condition-codes.md): the 12 conditions, codes 0 to 11; page 140.
- [TABLE C-2 Modifier codes: AA to DZ](020-table-c-2-modifier-codes-aa-to-dz.md): rows AA to DZ, 40 of 120; pages 141 to 144.
- [TABLE C-2 Modifier codes: EA to HZ](030-table-c-2-modifier-codes-ea-to-hz.md): rows EA to HZ, 40 of 120; pages 145 to 148.
- [TABLE C-2 Modifier codes: JA to MZ](040-table-c-2-modifier-codes-ja-to-mz.md): rows JA to MZ, 40 of 120; pages 149 to 152.
