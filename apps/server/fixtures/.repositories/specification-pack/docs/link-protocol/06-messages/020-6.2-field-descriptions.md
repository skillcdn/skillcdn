## 6.2 Field descriptions

The fields of the messages that a resumption and a loss of the carrier exchange. The definitions themselves are in [6.1](010-6.1-message-definitions.md#6.1).

### ResumeGuardTimes field descriptions

| Field | Description |
|---|---|
| g21 | The time a buoy waits after a LinkResumeRequest before it sends the next. |
| g22 | The time after which a buoy gives the resumption up. |
| maxRetryCount | How many requests a buoy sends within g22 at the most. |

### LinkResumeRequest field descriptions

| Field | Description |
|---|---|
| lastHeard | The sequence number of the last KeepAlive the buoy knows to have been heard. |
| attempt | Which request of this resumption it is, counted from one. |

### CarrierLossReport field descriptions

| Field | Description |
|---|---|
| silent | The count of windows without carrier at which the loss was declared, at most maxSilentWindows. |
