# 6 Messages

## 6.1 Message definitions

Each message is defined once, in the notation below. A field named in a procedure is a field of the definition here.

### 6.1.1 LinkSetupRequest

The shore station asks a buoy to set a link up.

```tln
LinkSetupRequest ::= RECORD {
    berth      BerthCode,
    buoy       BuoyAddress,
    channel    INTEGER (1..12),
    guard      ResumeGuardTimes
}
```

### 6.1.2 LinkSetupConfirm

The shore station confirms the link a buoy answered for.

```tln
LinkSetupConfirm ::= RECORD {
    buoy       BuoyAddress,
    window     INTEGER (0..59)
}
```

### 6.1.3 KeepAlive

A bound buoy says that it is there.

```tln
KeepAlive ::= RECORD {
    buoy       BuoyAddress,
    sequence   INTEGER (0..65535)
}
```

### 6.1.4 LinkRelease

Either station ends the link.

```tln
LinkRelease ::= RECORD {
    buoy       BuoyAddress,
    reason     ENUMERATED { keeper, hand-over, fault },
    nextBerth  BerthCode OPTIONAL
}
```

### 6.1.5 LinkResumeRequest

A buoy asks to take a lost link up again.

```tln
LinkResumeRequest ::= RECORD {
    buoy       BuoyAddress,
    lastHeard  INTEGER (0..65535),
    attempt    INTEGER (1..maxRetryCount)
}
```

### 6.1.6 LinkResumeAccept

The shore station takes the link up again.

```tln
LinkResumeAccept ::= RECORD {
    buoy       BuoyAddress,
    window     INTEGER (0..59)
}
```

### 6.1.7 LinkResumeReject

The shore station declines for now and says how long to wait.

```tln
LinkResumeReject ::= RECORD {
    buoy       BuoyAddress,
    g21       Milliseconds (100..6000)
}
```

### 6.1.8 ResumeGuardTimes

The guard times that bound a resumption.

```tln
ResumeGuardTimes ::= RECORD {
    g21       Milliseconds (100..6000),
    g22       Milliseconds (1000..60000),
    maxRetryCount  INTEGER (1..8)
}
```

### 6.1.9 CarrierLossReport

A shore station reports that it lost the carrier of a buoy.

```tln
CarrierLossReport ::= RECORD {
    berth      BerthCode,
    buoy       BuoyAddress,
    silent     INTEGER (1..maxSilentWindows)
}
```

### 6.1.10 RecoveryReport

A shore station reports how a loss ended.

```tln
RecoveryReport ::= RECORD {
    buoy       BuoyAddress,
    lostFor    Milliseconds,
    condition  StationCondition,
    modifiers  ModifierList OPTIONAL
}
```

### 6.1.11 StationCondition

One code of TABLE C-1.

```tln
StationCondition ::= RECORD {
    code       INTEGER (0..11)
}
```

### 6.1.12 ModifierList

Up to four codes of TABLE C-2.

```tln
ModifierList ::= RECORD {
    codes      SEQUENCE (1..4) OF ModifierCode
}
```
