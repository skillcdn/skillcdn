# Tidewater Link Protocol, third edition

The specification of the link between a marker buoy and the shore station that tends it, as the Vendrel Harbour Board issued it. The chapters are in the order of the original; a chapter too long for one file is a folder with a map of its own.

- [1 Scope and terms](01-scope-and-terms.md): what the protocol covers, its terms and its abbreviations; pages 1 to 6 of the original.
- [4 Link control](04-link-control/README.md): the states of a station and the link procedures, clauses 4.1 to 4.2.8; pages 31 to 58.
- [6 Messages](06-messages/README.md): the definition of every message and the description of its fields, clauses 6.1 and 6.2; pages 74 to 96.
- [Annex C Code tables](annex-c/README.md): the station condition codes and the modifier codes, TABLE C-1 and TABLE C-2; pages 140 to 151.
- [Index](index/README.md): where each definition and each table stands.
