A license text that quotes a permissive license is no longer read as that license. The Functional Source License and the Business Source License name the license they turn into later, and a permissive text with the Commons Clause added quotes the text it conditions; each is now read as the restrictive license it names itself. The Functional Source License is recognized by its text, as `FSL-1.1-ALv2` or `FSL-1.1-MIT` (and as a declared `license` field), and so is the Elastic License 2.0.
