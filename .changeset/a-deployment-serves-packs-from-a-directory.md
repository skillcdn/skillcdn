A deployment serves packs from a directory of its own at `local` addresses (ADR-0071). In `@skillcdn/core`, the coordinates of the git-host port (`RepoCoordinates.host`) carry any host of an address, `sourceFileUrl` and `rawFileUrl` take one and answer the page of the address at the file for `local`, which the new `localFileUrl` builds, and the REST repository's `avatar` is documented as the empty string for an owner with no picture. `@skillcdn/indexer` exports `readWorkingTree` and `LocalFile`, the files of a directory as tree entries with their bytes, and `BuildIndexOptions.repository.host` takes any host of an address.
