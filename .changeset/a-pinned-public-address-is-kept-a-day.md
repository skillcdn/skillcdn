A ready answer of the REST routes for a public address pinned to a full commit hash says `cache-control: public, max-age=86400`, so that a cache in front of a deployment keeps it a day, the bound the skills extension gives such an address as `ttlMs`; `restCacheControl` says it for a mount. Everything else stays `no-store`: an error, an answer given while the commit is indexed, a moving ref, and a private repository, whose answers a shared cache must not give without the permission check. `PINNED_TTL_MS` names the day.
